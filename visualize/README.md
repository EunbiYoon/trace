# Project page

Static page in the style of the MARSHAL project page, published by
`.github/workflows/pages.yml` to `https://eunbiyoon.github.io/trace/`.

| File | Role |
|---|---|
| `template.html` | Page layout, styles and the replay viewer (edit this) |
| `build.py` | Fills tables/links into the template and embeds replay episodes |
| `demo_episode.json` | Placeholder replay (teacher blind rollout, labelled as such) |
| `index.html` | Build output; regenerated by the workflow on every push |

```bash
python visualize/build.py                                   # placeholder replay
python visualize/build.py --rollout runs/<RUN_ID>/eval/rollouts/rw.jsonl \
    --variant rw --games pd-classic,stag-hunt,auction        # real checkpoint play
```

`--rollout` embeds every episode of the selected games (no cherry-picking).
Without rebuilding, the page's "Load a rollout .jsonl" link replays a local
file in the browser.

While the paper is under double-blind review, `PAPER_URL` and `BIBTEX` in
`build.py` are empty, so the Paper button and the BibTeX section are omitted.
Fill them in once there is a public OpenReview or arXiv link.
