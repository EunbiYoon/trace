Teacher-separated Reasoning and Actions with Counterfactual Evaluation

Overview

Frontier LLMs can explain how an agent should respond to another player's behavior, yet often fail to execute that strategy. Against tit-for-tat (TFT), an opponent that copies the model's previous action, Haiku 4.5, Gemma 3–27B and Llama 3.3–70B all earn a cumulative reward of only 1.50, exactly matching an untrained Qwen 2.5–3B. They defect early, trigger retaliation and never recover, while writing fluent reasoning about reciprocity. Standard distillation therefore has no better strategic actions to teach a small model.

TRACE is a preference-data recipe that assigns each training target to the source best equipped to provide it:

  • Action teacher — exact game solver. Computes the action that would have earned the highest reward against the opponent's recorded move.
  • Reasoning teacher — frontier LLM. Writes supporting reasoning conditioned on the solver action and the preceding history, but never on the opponent's simultaneous move.
  • Credit — counterfactual rollout. Rejects locally attractive actions that reduce return over the remaining horizon.

Figure 1. Each preference pair combines three independent sources: the solver supplies the action, the frontier model supplies the rationale, and an exact rollout supplies sequential credit.

Solver-pinned best response

At round \(t\), the solver replaces the student's recorded action with the ex-post best response to the opponent's realised move:

\[ \mathrm{BR}_0(a^1_t) = \arg\max_{a \in A_0} u_0(a, a^1_t). \]

For matrix games the solver enumerates \(|A_0|\) payoffs against the recorded opponent column. In a first-price auction the best response to bid \(b_1\) is the smallest legal bid above \(b_1\) when the private value exceeds it, and zero otherwise. In three-issue bargaining with capacity \(c\), the take-the-rest proposal \(p_0[i] = c - p_1[i]\) maximises utility. Because the opponent's current move is hidden at decision time, this label is a hindsight candidate until the horizon filter accounts for retaliation.

No-leakage frontier paraphrase

The solver gives no natural-language supervision, so Haiku 4.5 writes reasoning that supports the solver action under one central constraint:

The other player's current-round move is not observable at decision time. Never reference it as observed. Express the decision as belief-state reasoning from the prior history; expected-value arithmetic must average over posterior opponent types; and the final decision must match the supplied solver action.

Across 688 final oracle rounds, a regex audit and manual inspection found no current-move leakage. Replacing Haiku with Sonnet as paraphraser in a 30-episode pilot produced no further reward gains: once the action is supplied, the paraphraser only has to express a consistent rationale.

Counterfactual horizon filter

The best response is myopic: against a cooperator it recommends defection even when retaliation makes that choice harmful. Because training opponents are deterministic, each candidate is evaluated by exact rollout. The horizon-aware value is

\[ V(s, h_s) = \max_{a \in A_0} \Big[ u_0\big(a, \pi_{\text{opp}}(h_s)\big) + V\big(s+1,\; h_s \oplus (a, \pi_{\text{opp}}(h_s))\big) \Big], \qquad V(T,\cdot) = 0, \]

and a pair is emitted only when the recorded prefix, the candidate's stage reward and \(V(t+1, h^*_{t+1})\) together exceed the recorded return. For \(T \le 10\) with binary actions, exhaustive evaluation is cheap.

Algorithm 1 TRACE data construction (per episode) 1: Roll out blind trajectory τ_blind = (x, ρ_blind, a_blind) 2: for round t = 0, …, T−1 do 3: a* ← BR₀(a¹_t) // solver best response 4: if a* ≠ a⁰_t,blind then 5: compute exact return (Eq. 2 or Eq. 3) 6: if counterfactual return > R(τ_blind) then 7: generate no-leak reasoning ρ*_t; emit pair 8: end if 9: end if 10: end for

Analysis

Reasoning–action coupling

Coupling is the fraction of parsable rounds whose action equals the argmax of the model's stated expected values. It is a diagnostic, not an optimisation target: actions can consistently follow stated reasoning and still be strategically wrong. Frontier models' actions contradict the argmax of their own stated EVs in 15–70% of final rounds, depending on model and game.

Specialist adapters combine by plain averaging

The auction-heavy AUX adapter and the repeated-game-heavy ALL adapter are complementary. Averaging all 504 corresponding LoRA tensors, \(W_{\text{merge}} = \tfrac12 W_{\text{AUX}} + \tfrac12 W_{\text{ALL}}\), with no further training reaches 13.92 ID and +1.75 HO reward, against 13.93 and +1.91 for the reweighted retrain (RW).

The failed precursor: coupling-filtered frontier DPO

Before TRACE, a full DPO pipeline pinned chosen-side actions to the frontier model's own play and kept only “coupled” trajectories. The thesis did not survive the data: ID final-round coupling fell from 0.77 (base) to 0.66 with the filter and 0.55 without it, and neither variant reached positive HO reward. The filter selected a narrower slice of essentially the same action distribution — it could remove internally inconsistent traces, but not a prior, payoff estimate or action that was consistently reasoned yet strategically wrong. TRACE changes the object being supervised: the chosen action itself comes from the solver.

Limitations

  • Each game cell contains n = 12 episodes, so differences below roughly 0.2 CR should be read as ties.
  • One 3B base, one solver family, one paraphraser and deterministic training opponents. Stochastic opponents would need estimated counterfactuals; tic-tac-toe needs a sequential solver such as minimax.
  • Solver labels and the horizon filter are introduced together, so their contributions are not separately identified.
  • TRACE does not surpass Haiku 4.5 in aggregate ID reward or in coupling.
  • Matching Pennies and tic-tac-toe score zero for every model under the current reward metric and do not separate variants.
